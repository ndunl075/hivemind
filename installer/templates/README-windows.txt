Hivemind setup (Windows)

1. Right-click this zip and choose "Extract All". Do not run the setup from inside the zip.
2. Open the extracted folder and double-click "Hivemind Setup.cmd".
   This build is not signed yet, so Windows shows "Windows protected your PC":
   click "More info", then click "Run anyway".
3. Drag your project folder onto the window, press Enter, and follow the questions.
   You need the server address and your personal token from whoever runs your team's Hivemind.

You do not need Node or any other tool installed. When setup is done you can delete this folder.
